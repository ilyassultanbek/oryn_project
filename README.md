# ORYN

Алматыдағы автотұрақтарды тізімнен және картадан қарауға, олардың бағасы мен бос орын санын салыстыруға арналған full-stack оқу жобасы. MVP құрамына қолданушы кабинеті мен әкімші панелі кіреді.

## Мүмкіндіктер

**Қолданушы үшін:**

- Тұрақтар тізімін, аудан және тұрақ түрі бойынша беттерді қарау.
- Тұрақтарды сұрыптау, картадағы орналасуын және толық мәліметін көру.
- Тіркелу, жүйеге кіру және шығу; профиль мен құпиясөзді өзгерту.
- Тұрақтарды таңдаулыларға қосу және алып тастау.
- Пікір мен баға қалдыру, өз пікірлерін өңдеу және жою.
- Байланыс формасы арқылы хабарлама жіберу.

**Әкімші үшін:**

- Тұрақтарды қосу, өңдеу, жою және картадан қарау.
- Бос орын санын қолмен жаңарту.
- Қолданушы рөлдерін басқару және тұрақ иелерін тағайындау.
- Пікірлерді модерациялау, хабарламалардың мәртебесін өзгерту.
- Жинақталған статистика мен аналитиканы қарау.

Жария пікірлер тізімінде тек мақұлданған пікірлер көрсетіледі. Қорғалған API сұрауларында сервер сессияны, ал әкімші әрекеттерінде рөлді де тексереді.

## Технологиялар

| Қабат | Технологиялар |
| --- | --- |
| Интерфейс | React, Vite, React Router, Tailwind CSS |
| Карта | Leaflet |
| Сервер | Node.js, Express |
| Дерекқор | PostgreSQL, `pg` |
| Кіру | Серверлік сессия, HttpOnly cookie, bcrypt |

Негізгі авторизация серверлік сессияға негізделген: кездейсоқ токен браузерге cookie арқылы беріледі, оның SHA-256 хэші дерекқорда сақталады. Құпиясөздер bcrypt арқылы хэштеледі.

## Құрылым

```text
backend/
  config/          PostgreSQL қосылымы
  controllers/     API логикасы және SQL сұраулары
  middleware/      Сессия, рөлдер, қателерді өңдеу
  routes/          Express маршруттары
  utils/           Валидация
bosturak/
  src/
    app/           Маршруттар
    assets/        Беттер және UI компоненттері
    context/       Ортақ күй
    hooks/         Интерфейс логикасы
    services/      API сұраулары
    utils/         Көмекші функциялар
```

## Жергілікті іске қосу

Алғышарттар: Node.js пен npm, іске қосылған PostgreSQL және жобаға сәйкес дайын дерекқор. Командаларды репозиторийдің түбірінен орындаңыз.

### 1. Тәуелділіктерді орнату

PowerShell, macOS және Linux терминалдары үшін:

```sh
npm --prefix backend ci
npm --prefix bosturak ci
```

### 2. Сервердің орта айнымалылары

PowerShell:

```powershell
Copy-Item backend/.env.example backend/.env
```

macOS немесе Linux:

```sh
cp backend/.env.example backend/.env
```

`backend/.env` ішіндегі PostgreSQL қосылымын өз ортаңызға сәйкес толтырыңыз. Жергілікті іске қосуда сервер порты мен frontend адресі мынадай болуы керек:

```dotenv
PORT=3000
APP_ORIGIN=http://localhost:5173
```

### 3. Дерекқорды дайындау

**Репозиторийде әзірге SQL схемасы, миграциялар және бастапқы деректерді орнататын seed скрипті жоқ.** Сондықтан `npm ci` бос дерекқорға қажетті кестелерді автоматты түрде жасамайды. Қосымшаны толық іске қосу үшін жобаға сәйкес дайын базаны қалпына келтіру немесе схеманы кодтағы SQL сұрауларына сай бөлек дайындау қажет.

Код келесі кестелерді қолданады:

| Кесте | Мақсаты |
| --- | --- |
| `public.users` | Қолданушылар мен рөлдер |
| `public.sessions` | Кіру сессиялары |
| `public.parkings` | Тұрақтар, координаттар, бағалар, бос орын саны |
| `public.favorites` | Қолданушының таңдаулы тұрақтары |
| `public.parking_reviews` | Пікірлер, бағалар, модерация мәртебесі |
| `public.contact_messages` | Байланыс формасының хабарламалары |
| `public.oryn_notifications` | Хабарландыру модулінің деректері |

Бұл тізім толық DDL схемасын алмастырмайды: баған түрлері, шектеулер, байланыстар және әдепкі мәндер де қолданбаға сәйкес болуы керек. Алғашқы әкімшіні автоматты түрде жасайтын скрипт жоқ.

### 4. Backend-ті іске қосу

Бірінші терминалда:

```sh
cd backend
npm run dev
```

Сервер: `http://localhost:3000`. Қосылымды тексеру: `GET http://localhost:3000/api/v1/health`. Бұл endpoint базаға қосылуды тексереді; барлық кестелердің дайындығын және барлық функциялардың жұмысын растамайды.

### 5. Frontend-ті іске қосу

Екінші терминалда, репозиторий түбірінен:

```sh
cd bosturak
npm run dev
```

Браузерде **`http://localhost:5173`** адресін ашыңыз. `127.0.0.1` немесе басқа порт қолданылса, браузер origin-і `APP_ORIGIN` мәніне сәйкес келмейді және кейбір сұраулар қабылданбайды. Vite 5173 орнына басқа порт таңдаса, портты босатыңыз немесе конфигурацияны сәйкестендіріңіз.

## Құрастыру және тексеру

Репозиторий түбірінен:

```sh
npm --prefix bosturak run build
npm --prefix bosturak run lint
```

Frontend құрастырылымын жергілікті қарау:

```sh
npm --prefix bosturak run preview
```

Preview басқа портта ашылуы мүмкін; API-мен жұмыс істеу үшін origin конфигурациясын соған сәйкестендіру қажет. Backend-ті watch режимінсіз іске қосу командасы: `npm --prefix backend start`.

Автоматтандырылған тесттер әзірге қосылмаған. Backend-тегі `npm test` — бастапқы placeholder; build пен lint функционалдық немесе интеграциялық тесттерді алмастырмайды.

## Ағымдағы шектеулер және келесі қадамдар

- Брондау, төлем және датчиктерден нақты уақытта дерек алу іске асырылмаған. Бос орын саны әкімші енгізген соңғы деректі көрсетеді.
- Негізгі frontend services файлдары API адресін `http://localhost:3000` деп бекітеді. Жария ортаға шығару алдында API конфигурациясын ортақтандыру қажет; тек `VITE_API_URL` орнату барлық модульді өзгертпейді.
- Дерекқор миграциялары, seed деректері және автоматтандырылған тесттер қажет.
- Бос орындар панелі мен ортақ тұрақтар күйінің жаңаруын синхрондау қажет. Бөлек панельде бос орын санын өзгерткеннен кейін басқа бөлімде тұрақты өңдемес бұрын бетті толық жаңартыңыз.
- Хабарландыруларға арналған backend және UI компоненті бар, бірақ модуль ағымдағы навигацияға қосылмаған.
- Email арқылы құпиясөзді қалпына келтіру әзірге қосылмаған.

Жоба жергілікті оқу және MVP сценарийлеріне арналған. Келесі кезеңнің мақсаты — оны басқа ортада қайталап іске қосуға ыңғайлы ету және негізгі әрекеттерді тесттермен бекіту.
